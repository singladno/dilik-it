# Плейбук лидов Dilik (без «сети как основного канала»)

Цель: 1 платящий клиент за 30–60 дней. Бюджет рекламы ≤ 5 000 ₽.

## Оффер для касаний

Одна фраза: «Помогаю запустить MVP SaaS / встроить AI за 8–12 недель. Пришлите ТЗ или описание — вернусь с предложением по этапам, срокам и бюджету.»

Не писать: «делаем сайты / любые проекты / полный спектр», «созвон 30 минут», «продающая презентация».

## Неделя 1 — тёплая сеть (P1)

- 20 личных сообщений коллегам / знакомым / бывшим заказчикам.
- Шаблон: открыл практику Dilik (SaaS/AI) → если у кого задача — пришлите описание → вернусь с предложением.
- Цель: 3–5 диалогов.

## Каждую неделю — outbound (P2)

- 5–10 адресных писем / TG / LinkedIn.
- Одно конкретное наблюдение по продукту адресата + оффер выше.
- Площадки вторично: Kwork, FL.ru, TG-биржи заказов (не основной объём).

## Контент (P3)

- 1 пост в неделю (TG или LinkedIn).
- 1 статья на Хабр раз в 2 недели (кейс / разбор архитектуры / AI в продукте).
- Ожидание лидов: месяц 2–3.

## Реклама (P4) — только после сайта в проде

- Не Директ «разработка сайтов».
- Если тестировать: один оффер («аудит архитектуры SaaS» / «оценка MVP») в VK/TG, бюджет из остатка ≤ 2 700 ₽.

## Воронка ответа

1. Ответ ≤ 1 рабочий день.
2. Предложение: этапы, сроки, ориентир по бюджету (после ТЗ / описания).
3. Договор → предоплата → старт работ.

## Трекинг

- Яндекс.Метрика на сайте.
- Заявки → Telegram-бот.
- Таблица: касание → ответ → предложение → договор.

# Go-to-market: лиды, CRM, личный бренд

## Контекст

Сайт сам по себе не приведёт клиентов в первый месяц. SEO разогревается 3–6 месяцев, прямой трафик с поиска по бренду пока ноль. Поэтому первые лиды — это активные действия:

1. **Личный бренд** (контент-маркетинг) — даёт лиды через 3–6 месяцев, но это самый дешёвый и качественный канал.
2. **Сеть** (бывшие коллеги, друзья) — даёт первых клиентов в первый месяц.
3. **Outbound** (адресные предложения, биржи) — поддерживающий канал.
4. **Реклама** — только когда сайт умеет конвертить, иначе сольёшь бюджет.

Все лиды → CRM. С первого дня.

---

## 1. Личный бренд

Цель — стать «архитектором, к которому идут с задачами по SaaS и AI». Не «студия Dilik», а **личность**, на которую подписываются.

### 1.1 Telegram-канал

**Название:** что-то про твоё имя или роль. Например:

- «Дилик пишет про SaaS» — нормально, бренд-нейтрально.
- «Архитектор и его проекты» — про роль.
- «<твоё имя> об IT» — про человека.

НЕ называй канал «Компания Dilik» — это убивает личностность.

**Контент-план на 4 недели:**

| Неделя | Понедельник         | Среда                     | Пятница                    |
| ------ | ------------------- | ------------------------- | -------------------------- |
| 1      | Архитектурный приём | Разбор фейла из практики  | Анонс концепт-кейса        |
| 2      | Стек / инструмент   | Технический мини-туториал | Ответ на вопрос подписчика |
| 3      | AI-приём            | Сравнение технологий      | Заметка про управление     |
| 4      | Цена/ценность       | История из найма          | Анонс новой услуги/кейса   |

**Что НЕ постить:**

- Перепосты чужих новостей.
- «Доброе утро, друзья!».
- Цитаты Илона Маска.
- Открытки на день программиста.

**Цель к 3 месяцам:** 1000 подписчиков. Это даёт первые входящие лиды.

### 1.2 Хабр

Самый высококонверсионный контент-канал для IT-аудитории в РФ.

**Целевой формат статей:**

- **«Как мы делали **_ за _** недель»** — практический кейс с числами и кодом.
- **«5 ошибок при выборе \_\_\_»** — полезный разбор, всегда заходит.
- **«Сравнение **_ vs _** в 2026»** — для лидов через поиск.
- **«Архитектурный приём: \_\_\_»** — короткие технические заметки.

**Ритм:** 1 статья / 2 недели на старте, потом 1 в неделю.

**Что важно:** в каждой статье — ссылка на сайт в bio. НЕ кричи «закажите у нас», статья продаёт сама — экспертизой.

**Пример заголовков, которые сразу принесут читателей:**

- «Как мы выбрали LLM для on-premise RAG: сравнили Llama 3, Qwen, GigaChat»
- «Биллинг в SaaS: разбор архитектуры, которая выдерживает изменение цен задним числом»
- «Что не так с fix-price в разработке (и когда он всё-таки работает)»

### 1.3 LinkedIn / Хабр Карьера / других площадках

Если работаешь с международными клиентами — LinkedIn. Иначе сосредоточь силы на одной-двух площадках.

## 2. CRM-воронка (минимум на старте)

С первого лида заведи систему, иначе через 2 месяца не вспомнишь кому что обещал.

### 2.1 Минимальный вариант — Notion

База данных «Лиды» с полями:

| Поле                    | Тип    | Значения                                                    |
| ----------------------- | ------ | ----------------------------------------------------------- |
| Имя                     | text   |                                                             |
| Компания                | text   |                                                             |
| Контакт                 | text   | email / telegram / телефон                                  |
| Источник                | select | сайт, telegram, рекомендация, хабр, outbound                |
| Услуга                  | select | saas, ai, mobile, web, консультация                         |
| Бюджет                  | select | <500k, 500k-1.5m, 1.5m-3m, >3m                              |
| Статус                  | select | новый, квалификация, демо, оценка, договор, активен, закрыт |
| Тёплость                | select | холодный, тёплый, горячий                                   |
| Дата первого контакта   | date   |                                                             |
| Дата последнего касания | date   |                                                             |
| Дата следующего касания | date   |                                                             |
| Причина отказа          | select | дорого, нет ТЗ, передумали, выбрали другого, тишина         |
| Сумма (если в работе)   | number |                                                             |
| Заметки                 | text   |                                                             |

**Доска «Pipeline»:** kanban с статусами (новый → квалификация → демо → оценка → договор → активен).

### 2.2 Когда переходить на полноценную CRM

Когда лидов > 20 в месяц или активных проектов > 3 — Notion начинает ломаться. Переходи на:

- **amoCRM** (стандарт в РФ, удобный, недорогой).
- **Bitrix24** (если работаешь с госом, они любят).
- **Pipedrive** (если работаешь с международными клиентами).

### 2.3 Правила гигиены

- **24 часа.** Любой лид получает первый ответ в течение 24 часов.
- **Никогда не оставляй «зависший» лид.** Если 7 дней нет ответа — финальное письмо «закрываю как неактивный, готов вернуться когда будете готовы».
- **Каждое касание = запись в CRM.** Созвон, письмо, сообщение — всё.
- **Постмортем каждого закрытого лида.** Почему выиграли / проиграли — это материал для улучшения процесса.
- **Раз в месяц** — проход по «холодным» лидам с реальным напоминанием о себе (не «не передумали ли?», а «вот написал статью, может быть полезно»).

## 3. Outbound на первых месяцах

### Где искать клиентов адресно

- **Habr Фриланс / Хабр Тендеры** — большие проекты, можно фильтровать по сумме.
- **Profi.ru / FL.ru** — много мусора, но иногда попадаются нормальные.
- **YouDo Бизнес** — для маленьких проектов.
- **Биржи на Telegram-каналах** (например, @workout_jobs, @rabota_v_it).
- **LinkedIn** для международных клиентов.

### Письма / сообщения по холодным контактам

**Что НЕ работает:**

- «Здравствуйте! Мы разрабатываем сайты под ключ...»
- «Не хотите ли заказать у нас MVP?»

**Что работает:**

- Конкретная польза по их конкретной ситуации.
- Доказательство, что ты разобрался в их бизнесе (упоминание их продукта, фичи, поста в соцсетях).
- Один маленький вопрос, не «всё купите у нас».

**Шаблон письма:**

```
Тема: <конкретное наблюдение про их продукт>

Здравствуйте, <имя>.

Зашёл на <их сайт/продукт>. Заметил, что <конкретное наблюдение —
проблема в UX, медленная страница, отсутствует фича, которую заявляли
в посте, и т.п.>.

Решал похожую задачу в <название твоей услуги>. У нас типичный путь:
<1-2 предложения о подходе>.

Если интересно — напишу разбор, без обязательств. Не интересно — извиняюсь
за беспокойство.

—
<Имя>, архитектор / Dilik
<ссылка на сайт>
```

**Ритм:** 5–10 таких писем в неделю. Конверсия 5–10% — это уже 0.5–1 лид в неделю.

## 4. Сеть (warm reach)

Самый недооценённый канал. У тебя 10 лет в IT — это сотни бывших коллег, знакомых, друзей друзей.

### Что сделать в первый месяц

1. **Объяви о запуске.** Один пост в LinkedIn / FB / Telegram-каналах, где ты есть: «открыл свою практику, делаю SaaS и AI. Если у вас или у знакомых есть задача — буду рад поговорить».
2. **Личные сообщения 20 ключевым контактам.** Не «купи у меня», а «привет, хотел сообщить — открыл практику, если у тебя или твоих коллег будет задача по SaaS / AI, помни обо мне».
3. **Реферальная программа.** «Если приведёшь клиента — 10% от первого проекта». Это работает.

## 5. Платная реклама — НЕ сейчас

Включай только когда:

- Конверсия сайта измерена (по Метрике: visit → форма ≥ 1%).
- Понятно, кто целевой клиент, что им показывать.
- Есть деньги на 3 месяца теста (минимум 100 тыс. ₽/мес).

Раньше — слив бюджета. Сначала органика, потом усиление платным.

## 6. KPI на первые 6 месяцев

| Месяц | Лидов / мес | Сделок | Контентные посты     | Активных проектов |
| ----- | ----------- | ------ | -------------------- | ----------------- |
| 1     | 5           | 0–1    | 4 поста + 1 статья   | 0–1               |
| 2     | 10          | 1–2    | 8 постов + 2 статьи  | 1–2               |
| 3     | 15          | 2      | 12 постов + 4 статьи | 2                 |
| 4     | 20          | 2–3    | 12 постов + 4 статьи | 2–3               |
| 5     | 25          | 3      | 12 постов + 5 статей | 3                 |
| 6     | 30+         | 3+     | 12 постов + 6 статей | 3+                |

Это **очень** оптимистичный сценарий. Реальный может быть в 1.5–2 раза медленнее. Не паникуй, если первые 2 месяца — только 1–2 лида в неделю. Это норма.

## 7. Анти-советы

- **Не тратьcя на брендинг до первых клиентов.** Логотип, фирменный стиль, мерч — пока не нужны.
- **Не делай рассылки в «холодные» базы.** Это незаконно по 152-ФЗ, отвратительно по UX и не работает.
- **Не предлагай скидки незнакомым клиентам.** Скидка для убеждения сомневающегося клиента = слабая позиция.
- **Не делай первый проект бесплатно «для портфолио».** Бесплатные проекты не доводят до конца ни клиент, ни исполнитель.
- **Не «нанимай маркетолога» в первые 3 месяца.** Лиды через контент должен качать ты сам — тогда это будет правда тобой.
